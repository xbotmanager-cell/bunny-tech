HOW TO USE BUNNY CURRENCY

Converting Money

  1. Enter the amount you want to convert in the first box
  2. Select the currency you are converting FROM in the first dropdown
  3. Select the currency you are converting TO in the second dropdown
  4. Tap the CONVERT button
  5. Wait for the loading indicator to finish
  6. Your converted amount appears with live exchange rates

Swap Currencies Quickly

  1. Tap the circular arrow button between the dropdowns
  2. This instantly swaps FROM and TO currencies
  3. Tap CONVERT again to see the reverse conversion

Live Data System

  1. Exchange rates update automatically from 15 worldwide sources
  2. If one server fails, the app tries the next one automatically
  3. Last update time is shown at the bottom for transparency
  4. Supports 160+ world currencies including TZS, USD, EUR, GBP, KES, UGX, ZAR, NGN
  5. Works on all devices - scroll down to access all features

Important Information

  1. Rates are for reference only - banks may use different rates
  2. All processing happens in your browser for complete privacy
  3. No personal data, accounts, or API keys are required
  4. The app works worldwide with no restrictions
