HOW TO PLAY

Basic Controls

  1. Tap anywhere on the screen to throw a knife
  2. Knives stick to the spinning log
  3. Don't hit other knives or you lose
  4. Throw all knives to complete the level

Scoring System

  1. Each knife: +10 points
  2. Hit an apple: +50 coins
  3. Throw 3 knives quickly: PERFECT bonus +30
  4. Complete level: +100 bonus

Level Progression

  1. Each level adds more knives to throw
  2. Log spins faster and changes direction
  3. Every 5th level is a Boss Level with apples
  4. Levels are infinite - how far can you go?

Boss Levels

  1. Appear every 5 levels (5, 10, 15...)
  2. Log has apples attached to it
  3. Hit apples to collect coins
  4. Missing an apple is okay, hitting a knife is not

Tips

  1. Watch the log rotation pattern before throwing
  2. Time your throws when there's a clear gap
  3. Don't rush - one bad throw ends the game
  4. Save coins to unlock cool knife skins
